# M0 Review Brief

## Review Goal

Review M0 implementation and evidence against the revised exit criteria while
separating technical qualification from public-release hygiene.

## Review State

The technical review is complete. The authoritative assessment is
[`docs/reviews/m0-review.md`](../reviews/m0-review.md).

Confirmed conclusions:

- Host CUDA and digest-pinned GPU-container smoke tests pass on both nodes.
- Both bootstrap replays record commit
  `784506a1b72727de0dcc774eabcbf9f623847438`, a clean tracked worktree, and
  exit code `0`.
- Both vLLM captures use the same immutable digest, initialize the model, and
  return HTTP 200. The outer exit `141` remains a non-blocking harness caveat.
- The canonical TCP bundle passes all wrapper stages: four streams / 30 seconds,
  96.7404 Gbit/s receiver throughput, 43,506 retransmissions, and 0% ping loss.
- NCCL `all_reduce` and `all_gather` exit `0` with zero correctness errors.
- Per-channel built-in `NET/IB` logs and local/remote raw RDMA counter deltas
  directly prove mlx5 RoCE/RDMA transport.
- GPUDirect RDMA is not active (`GDR 0`). SPCX external NET is not the payload
  path; CollNet is loaded but unqualified, and the SPCX tuner is active.
- The active `mpirun` reports Open MPI `5.0.10rc2`; installed distro Open MPI 4
  packages remain a version-selection boundary.
- All 13 private SHA256 manifests validate.

M0 does not claim clean-machine provisioning or reboot recovery. Their absence,
the lifecycle-only `hello-world:latest` identity, and missing per-layer replay
files are trivial/non-blocking under the revised criterion.
