    指标口径与 knee / boundary 判定边界

    TTFT

    从客户端提交请求到收到首个非空 generated content。它不是 server readiness，也可能包含排队与调度时间。

    TPOT

    每请求使用 (last content − first content) / (output tokens − 1)，再对请求级结果取分位；不是逐 token ITL。

    Percentile

    只基于成功请求。图中 median/min/max 是 repetition 汇总和范围，不是置信区间。

    Performance knee

    需要吞吐边际收益变平，同时 TTFT、queue 或资源压力出现一致恶化并能复现。最高成功并发不是 knee。

    Capacity boundary

    应由保留的 OOM、重复 timeout、服务不稳定或 useful throughput 退化界定，通常表达为最后健康点到首个失败点的区间。

    Unified Memory

    NVML process allocation、cgroup memory、Host MemAvailable、KV Cache 属于不同信号，不能相加，也不能把 unsupported 当作 0。
